# Export Enhancement

## 导出文件功能增强
---

### 适用范围
增加新的文件导出选项，不影响现有的CSV和Excel导出。

### 界面入口
在统计报表界面，导出XLSX按钮右边，增加一个新的按钮，命名为“导出账单报表”，点击后触发新的导出逻辑。

### 导出逻辑
根据选择的起止时间范围和筛选案件条件，找出该范围内的所有时间记录数据，过滤掉没有截止时间的记录。数据按照案件名称和日期进行分组处理。
* 对于每个分组里的记录，先进行合并处理：
  * 如果工作内容和注释完全相同，则这些记录会被合并成一条记录，时长字段为所有时长加总后换算成小时（未满6分钟的部分按0.1小时处理（向上对齐，至少0.1小时）），其他信息不变，同时删除原有记录（参与合并的记录）。
* 然后对每个分组里做完第一次合并的记录进行第二次合并处理：
  * 这些记录会被合并成一条记录，时长字段为所有时长（小时级别）加总，工作内容字段的值为对每条记录的工作内容进行合并，合并时取每条记录的工作内容和时长，按照”{工作内容}({时长})“的格式组合形成新的工作内容，多个新的工作内容之间以分号分割，其他信息不变，同时删除原有记录（参与合并的记录）。
* 至此，每个分组里就只对应一条记录了。然后对所有记录进行排序，排序规则为：案件名称+日期进行升序排列。

### 导出内容
表头包括：案件名称、日期，工作内容，时长（小时）。
* 案件名称对应记录的案件名称字段
* 日期对应记录的日期字段，类型为日期，形式为类似“2-Mar-26”这样的形式。
* 工作内容对应记录的工作内容字段。
* 时长对应记录的时长字段，类型为数值。
* 所有数据结束后，空一行之后，输出按案件名进行统计的统计行的内容：
    * 案件名称列为统计后的案件名称，日期列为空，工作内容列为“总计”，时长列为对该案件的时长进行加总后的结果，该结果为数值类型。
* 导出文件命名为“Chronos_账单报表_YYYYMMDD_HHmmss.xlsx”，其中“YYYYMMDD_HHmmss”为导出时的时间戳。
